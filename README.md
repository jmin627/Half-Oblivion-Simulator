# 🌌 절반 소멸 시뮬레이터 (Half Oblivion Simulator)

> **"우주의 절반을 날려볼까요?"**  
> 어벤져스의 손가락 튕기기(스냅)에서 영감을 받은 **우주적 블랙코미디 & 게이미피케이션 반응형 웹 애플리케이션**입니다.

---

## 📖 1. 프로젝트 소개

중앙의 우주 건틀릿을 클릭하거나 스와이프하여 **손가락을 한 번 튕길 때마다 세상의 무언가가 무작위로 선택되어 정확히 절반으로 감소하거나 사라지는 가상 시뮬레이션**입니다.

- **100% 안전한 가상 시뮬레이션**: 실제 기기 데이터, 메모리, 브라우저를 변경하지 않고 유머 가상 연출로만 동작합니다.
- **풍성한 게이미피케이션**: 단순 문구 생성을 넘어 **소멸 도감(Codex), 건틀릿 6단계 진화, 레벨업, 25+개 업적, 데일리 미션, 코스믹 상점, 성향 칭호**를 지원합니다.
- **프로시저럴 사운드 & 파티클**: Web Audio API 기반 합성음(스냅 소리, 서브 베이스 충격파, 희귀도별 팬파레)과 Canvas 2D 물질 분해 먼지 파티클을 탑재했습니다.

---

## ✨ 2. 핵심 기능

1. **코스믹 스냅 인터랙션**
   - 마우스 클릭, 모바일 스와이프 제스처, `[Space]` 키보드 단축키 지원
   - 화면 암전 플래시 → 건틀릿 튕김 → 사운드 & 충격파 → 먼지 분해 파티클 → 수치 감소 카운트다운 애니메이션
2. **120개 이상의 유머 타겟 (9개 카테고리)**
   - 🌍 세계/사회 (인구, 신호등, 출근길 지하철)
   - 🎓 대학/연구실/논문 (논문 데이터, Reviewer #2 코멘트, 교수님 수정사항, 멘탈, 월급)
   - 💻 컴퓨터/디지털 (가상 RAM, 크롬 탭 47개, 바탕화면 아이콘)
   - 🎮 게임 (보스 체력, 가챠 천장, 랭크 점수)
   - 🍗 음식 (치킨 조각, 라면 면발, 피자)
   - ❤️ 일상/인간관계 (카드값 😇, 통장 잔고 💀, 안 읽은 카톡)
   - 🐶 동물/자연 (모기 멸종 환호, 바퀴벌레, 고양이)
   - 🌌 우주/초현실 (지구 중력, 하루 12시간, 리모컨)
   - 😂 메타/개그 (웹사이트 글자 3초간 소멸 연출, 개발자 야근)
3. **건틀릿 6단계 진화**
   - Lv.1 낡은 작업용 장갑 → Lv.5 기계 장갑 → Lv.10 우주 장갑 → Lv.20 차원 건틀릿 → Lv.35 현실 조작 건틀릿 → Lv.50 전지전능한 신의 손길
4. **소멸 도감 (Codex) & 중복 레벨업**
   - 카테고리별 수집률 표시, 중복 획득 시 `⭐ Lv.2`, `⭐ Lv.3` 레벨업 및 숨겨진 로어(Lore) 해금
5. **특수 돌발 이벤트**
   - ⚡ DOUBLE SNAP (동시 2개 소멸), 🔄 UNO REVERSE (2배 폭증), 💥 CRITICAL SNAP (75% 소멸), 📐 WRONG SNAP (49.7% 오차), 🌟 확률 붕괴 (15초간 Rare+ 확률 급증)
6. **로컬스토리지 영구 저장**
   - 브라우저를 닫거나 새로고침해도 레벨, 도감, 업적, 재화(Dust)가 유지됩니다.

    ├── app.js           # 메인 애플리케이션 및 인터랙션 컨트롤러

        └── achievements.js # 업적, 건틀릿 티어, 일일 미션, 상점 데이터

## 💻 4. 로컬 실행 방법

### 방법 A: 간단한 웹 서버 실행 (권장)
```bash
# npx를 이용한 로컬 실행
npx serve .

# 또는 Python 내장 서버
python -m http.server 8080
```
브라우저에서 `http://localhost:3000` 또는 `http://localhost:8080`으로 접속합니다.

### 방법 B: 브라우저에서 직접 실행
- `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 더블 클릭하여 실행합니다.

## 🛠️ 6. GitHub 푸시 명령어 가이드

프로젝트 폴더에서 아래 명령어를 순서대로 실행하여 GitHub 저장소로 푸시할 수 있습니다:

```bash
# 1. Git 저장소 초기화 (처음 한 번만 실행)
git init

# 2. 모든 파일 스테이징
git add .

# 3. 커밋 메시지 작성
git commit -m "feat: complete Half Oblivion Simulator for Vercel deployment"

# 4. 기본 브랜치 이름을 main으로 설정
git branch -M main

# 5. 원격 저장소 연결 (본인의 저장소 주소)
git remote add origin https://github.com/jmin627/Half-Oblivion-Simulator.git

# 6. GitHub에 푸시
git push -u origin main --force
```

푸시가 완료되면 **Vercel**에서 해당 리포지토리를 Import하여 즉시 배포를 완료할 수 있습니다! 🎉
